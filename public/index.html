03 — Handbook

常见问题

关于 AI 图片生成器的使用疑问

如何开始使用？需要配置什么？ ▾

本工具默认使用 AIHubMix 统一接入引擎。你只需：① 登录 aihubmix.com/token 创建一个 API Key（支持支付宝/微信充值）；② 把 Key 粘贴到生成区顶部的输入框并保存（存在浏览器本地，随请求发送）；③ 输入提示词点击生成即可。也可以把 Key 写进 .env 的 AIHUBMIX_KEY。

支持哪些模型？有什么区别？ ▾

两个主引擎，可任意切换：

AIHubMix 覆盖 6 大跨厂商热门生图模型，包括 Nano Banana Pro（谷歌顶配）、Nano Banana 2（谷歌高速）、GPT Image 2（OpenAI·文字渲染）、Seedream 5.0 Pro（字节）、FLUX Kontext（BFL）、Z-Image Turbo（智谱）。支付宝/微信充值。

Hugging Face 提供 4 个公开 SDXL/SD 开源模型，免费可用。只需去 huggingface.co 建一个免费 token。

Pollinations 是备用引擎，$1 ≈ 1 pollen，支付宝 ¥10 起充。

AIHubMix / Pollinations 收费吗？ ▾

都支持支付宝充值（最低约 ¥10）。

AIHubMix：单张约 ¥0.05-2，模型不同价格不同。

Pollinations：单张约 $0.0001-0.02（pollen 计价）。

图生图功能如何使用？ ▾

切换到「图生图」标签页，上传参考图片（支持点击上传、拖拽上传、剪贴板粘贴），输入提示词描述你想要的改动，点击生成即可。

创意工坊能做什么？ ▾

「创意工坊」是高级编辑入口，提供 4 个场景模板：

① 局部编辑：上传 1 张图，写精准指令改颜色/加道具。

② 换装：上传 2 张图（图A=服装，图B=人物），自动换装。

③ 融合：上传 2 张图合成。

④ 换背景：保留主体换场景。

推荐使用 Nano Banana Pro 模型，效果最好。

我的 API Key 安全吗？ ▾

在网页粘贴的 Key 只存储在你的浏览器本地（localStorage），生成时随请求头发给你自己的本地服务端，不会上传到任何第三方。写进 .env 的 Key 已由 .gitignore 保护，不会被提交到仓库。
