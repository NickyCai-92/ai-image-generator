03 — Handbook

常见问题

关于 AI 图片生成器的使用疑问

如何开始使用？需要配置什么？ ▾

本工具默认使用 AIHubMix 统一接入引擎。你只需：① 登录 aihubmix.com/token 创建一个 API Key（支持支付宝/微信充值）；② 把 Key 粘贴到生成区顶部的输入框并保存（存在浏览器本地，随请求发送）；③ 输入提示词点击生成即可。也可以把 Key 写进 .env 的 AIHUBMIX_KEY。

支持哪些模型？有什么区别？ ▾

两个主引擎，可任意切换：

① AIHubMix（统一接入·付费）覆盖 6 大跨厂商热门生图模型：Nano Banana Pro（谷歌顶配·角色一致）、Nano Banana 2（谷歌高速·低成本）、GPT Image 2（OpenAI·文字渲染）、Seedream 5.0 Pro（字节·精准编辑）、FLUX Kontext（BFL·局部编辑）、Z-Image Turbo（智谱·极速）。支付宝/微信充值即可使用。

② Hugging Face（完全免费）提供 4 个公开 SDXL/SD 开源模型：SDXL Lightning（4 步极速·推荐免费）、SDXL 1.0（高画质）、SD 2.1（稳定基础款）、SD 1.5（经典款）。只需去 huggingface.co/settings/tokens 建一个免费 token 即可，零充值门槛。

此外还有 Pollinations 作为备用引擎（需 Token + 账户有 pollen 余额，支付宝充值最低约 ¥10）。模型列表在生成区顶部切换。

Hugging Face 的免费档有什么限制？ ▾

免费账户有两个特点：① 冷启动慢：首次调用一个模型需等 20-60s（HF 要把模型加载到 GPU worker），之后会快很多；② rate limit：免费账户每分钟调用次数有限（一般 3-10 次），所以 HF 模型单次只能生成 1 张。画质比 nano banana / GPT Image 2 略逊，但完全零成本出图够用。

AIHubMix / Pollinations 收费吗？大概多少钱？ ▾

两者都按量计费、无会员无包月，都支持支付宝充值（最低约 ¥10）。

AIHubMix：单张约 ¥0.05-2（Flux Schnell 最便宜、Pro 最贵）。具体以 aihubmix.com 计费说明为准。

Pollinations：原厂定价，单张约 0.0001-0.12 pollen（pollen ≈ $0.01）。Nano Banana 系列按输出 token 计费、Quest 模型可做任务免费拿 pollen。详见 enter.pollinations.ai/pricing。

图生图功能如何使用？ ▾

切换到"图生图"标签页，上传参考图片（支持点击上传、拖拽上传、剪贴板粘贴），输入提示词描述你想要的改动或风格，点击生成即可。图生图支持 AIHubMix 与 Pollinations 引擎；不同模型对图生图的支持程度不同，若某模型不支持会自动提示切换。

创意工坊能做什么？和图生图有什么区别？ ▾

"✦ 创意工坊"是一个独立的高级编辑入口，提供 4 个场景模板：

① 局部编辑：上传 1 张图，写精准指令"把头发染红""去掉背景文字"，其余不变。

② 换装：上传 2 张图（图A=服装参考 + 图B=人物），自动把图A的衣服换到图B身上。

③ 融合：上传 2 张图，合成一张——适合"图A的风格 + 图B的构图"这类需求。

④ 换背景：保留主体人物/物体不变，只换背景场景。

和图生图的区别：图生图是"1 张图 + 描述 → 变体"，适合风格迁移、变体创作；创意工坊是"多张图 + 场景 → 精准编辑"，适合换装、融合、局部修改。推荐使用 Nano Banana Pro 或 Nano Banana 2 模型（谷歌 Gemini 系列），对多图理解和编辑能力最强。换装/融合需要 2 张参考图，局部编辑/换景只需 1 张。

我的 API Key 安全吗？ ▾

在网页粘贴的 Key 只存储在你的浏览器本地（localStorage），生成时随请求头发给你自己的本地服务端，不会上传到任何第三方。写进 .env 的 Key 已由 .gitignore 保护，不会被提交到仓库。
